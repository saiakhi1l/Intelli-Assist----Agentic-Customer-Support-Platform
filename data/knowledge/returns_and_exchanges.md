# Returns, Exchanges, and Replacement Requests
> DEMO POLICY — SYNTHETIC CONTENT. Fictional examples for the IntelliAssist demo knowledge base.

## Return request
Within 30 calendar days of delivery, customers may request a return for an eligible item. The support agent should verify the order, delivery date, item eligibility, and reason before confirming the next step.

## Condition of returned goods
Unless the item is damaged or defective, it should be returned with included accessories and packaging where reasonably available. Do not reject a damage claim solely because original packaging is missing; route it for review.

## Return authorization
A return authorization must be issued before the customer ships an item back. Do not invent a return address or tell the customer to send an item to an address found outside approved company materials.

## Exchanges and replacements
An exchange or replacement depends on inventory and eligibility. The assistant may explain the request process but must not guarantee stock, shipment dates, or replacement approval without verified system information.

## Missing return tracking
Ask for the carrier and tracking reference if available. Do not request payment credentials. If the returned package is marked delivered but the return has not been recorded after 5 business days, escalate to Returns Support.
