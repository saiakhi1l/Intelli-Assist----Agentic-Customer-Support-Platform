# Multi-Factor Authentication and Login Troubleshooting
> DEMO POLICY — SYNTHETIC CONTENT. Fictional example rules for testing retrieval and support workflows.

## Authentication codes
One-time authentication codes expire after 10 minutes. Customers should check device time settings and request a fresh code if the current one has expired. Support must never ask a customer to paste a live code into chat.

## Lost or replaced device
If a customer no longer has the registered authentication device, direct them to the account recovery process. If recovery is unavailable, escalate to Account Support for identity verification. Do not disable multi-factor authentication solely because a requester knows the account email.

## Repeated login failures
Ask the customer to confirm the sign-in email, check keyboard layout and caps lock, and try a password reset. Do not recommend sharing credentials or turning off security protections.

## Suspicious authentication prompts
If the customer receives sign-in prompts they did not initiate, advise them not to approve them, to change their password from a trusted device, and to contact Security Support. Treat possible account compromise as high priority.

## Browser troubleshooting
The customer may try a supported, updated browser, a private window, and clearing site cookies. Do not ask them to install unknown remote-access software or provide remote control to an unverified person.
